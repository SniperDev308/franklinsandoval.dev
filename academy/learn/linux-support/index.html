01 / SHELL + FILESYSTEM

Know where you are and what changed

pwd # current directory

ls -lah # inspect files and permissions

cd /var/log # move through filesystem

find /var/log -type f # locate files

grep -Ri "error" /var/log # search content recursively

tail -f app.log # watch new log entries

02 / ACCESS

Permissions, ownership and privilege

chmod

Changes file permission bits. Ask who needs read, write or execute access before changing them.

chown

Changes file owner and/or group. Ownership problems can prevent services from reading configuration or writing data.

sudo

Runs an authorized command with elevated privileges. Use it deliberately, not as a universal troubleshooting hammer.

ls -l

Shows permission and ownership information that helps explain “permission denied” symptoms.

03 / SERVICE HEALTH

systemd and logs

systemctl status postgresql

systemctl status nginx

journalctl -u nginx --since "30 min ago"

ps aux | grep process-name

SUPPORT REFLEX

Separate “server is reachable” from “application process is healthy.” A responding host can still have a stopped service.

04 / NETWORK VIEW

From interface to listening socket

ip addr # interfaces and addresses

ip route # routing table

ss -lntp # listening TCP sockets/processes

curl -vk https://localhost # test HTTP/S locally

ping gateway-ip

dig app.company.local

SCENARIO

The server answers ping, but users receive “connection refused” to TCP 5432.

Before blaming the network, what should you prove on the Linux server?
Reveal reasoning

Verify that the expected service is running and that a process is actually listening on the expected address and TCP port. Then inspect logs and configuration.

05 / HANDS-ON LAB

Linux support drill

  1. Open a Linux environment or VM.
  2. Run pwd, ls -lah, ip addr and ip route.
  3. Identify one running service with systemctl.
  4. Use journalctl to inspect recent service messages.
  5. Run ss -lntp and identify at least one listening TCP port.
  6. Create a test text file and inspect its owner and permissions.
  7. Use grep to locate a word inside the file.
