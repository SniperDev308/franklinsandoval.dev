01 / MENTAL MODEL

Do not troubleshoot “the BMS” as one box

BMS workstation→IP network→BACnet device→Object→Property / value

A graphics page is the top of a chain. When a value is missing or stale, identify which layer stopped providing evidence.

02 / OBJECT MODEL

Points become objects with meaning

AI · Analog Input

Represents an analog input value, such as a measured temperature or pressure.

AO · Analog Output

Represents an analog output or command value.

BI · Binary Input

Represents a two-state input such as status or proof.

BO · Binary Output

Represents a two-state command/output.

OPERATOR SCENARIO

An AHU supply-air temperature has displayed exactly 72.0°F for two hours while nearby conditions changed.

Is 72.0°F proof that the sensor is healthy?
Reveal reasoning

No. A plausible value can still be stale. Check timestamp/update behavior, trend history, object communication and the physical signal chain before accepting the value.

03 / BACNET-IP

Controls traffic still lives on a network

BACnet/IP uses IP networking. That means subnet boundaries, routing, UDP traffic and network policy can become part of a controls incident. Your networking skills are now controls skills.

TROUBLESHOOTING CHAIN

1. Is the controller/device powered and operational?

2. Is its IP configuration plausible?

3. Is the local subnet reachable?

4. Are BACnet devices discoverable locally?

5. Does the problem begin only across a routed subnet?

6. Are BACnet broadcast-management requirements satisfied?

04 / ROUTED DISCOVERY

Why BBMD matters

IP routers normally do not forward local broadcasts between subnets. BACnet/IP deployments that require broadcast-based discovery across IP subnet boundaries can use a BACnet Broadcast Management Device, or BBMD, to support that communication architecture.

DIAGNOSTIC CLUE

If local BACnet devices are visible but devices on another subnet disappear, do not immediately blame every remote controller. First establish whether the failure aligns with the subnet boundary and inspect routing plus BACnet broadcast management.
