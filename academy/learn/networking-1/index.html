01 / MENTAL MODEL

Follow the packet

When a user says “the network is down,” do not begin with guesses. Build the path. What address does the host have? Is the destination local or remote? Which Layer 2 device forwards the frame? When does a router become necessary?

Application↓TCP / UDP↓IP↓Ethernet↓Physical link
Operational rule

Start at the symptom, then prove each dependency. A successful ping proves something, not everything.

02 / LAYER 2

Switching, ARP and VLAN boundaries

MAC table

A switch learns source MAC addresses and associates them with ports, then forwards frames using that table.

ARP

IPv4 hosts use ARP to resolve a local IPv4 address to a MAC address before Ethernet delivery.

Access port

Carries traffic for one access VLAN toward an endpoint.

802.1Q trunk

Carries traffic for multiple VLANs between network devices using VLAN tags.

SCENARIO

PC-A is in VLAN 10. PC-B is in VLAN 20. They are connected to the same Layer 2 switch.

Question: What additional function is required before they can communicate?
Reveal reasoning

Inter-VLAN routing. Their VLANs represent separate Layer 3 broadcast domains, so traffic must pass through a router or Layer 3 switching function configured to route between them.

03 / IPV4

Subnetting without ceremony

For support work, subnetting is a boundary detector. You need to decide quickly whether two addresses are local to each other and identify valid host ranges.

EXAMPLE192.168.50.64/27

/27 = 32 addresses per block

Network: 192.168.50.64

First host: 192.168.50.65

Last host: 192.168.50.94

Broadcast: 192.168.50.95

Usable hosts: 30

04 / HANDS-ON LAB

Packet Tracer: two VLANs, one boundary

Build a small topology that makes the Layer 2 / Layer 3 boundary visible.

  1. Add one switch and four PCs.
  2. Create VLAN 10 and VLAN 20.
  3. Place two access ports in each VLAN.
  4. Assign IPv4 addresses using two /24 networks.
  5. Verify same-VLAN connectivity.
  6. Attempt cross-VLAN connectivity and record the result.
  7. Add inter-VLAN routing and prove what changed.
