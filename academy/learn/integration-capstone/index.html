03 / INCIDENT OPS-102

BMS loses remote controllers

BMS UI          Available
LOCAL BACNET    Devices visible
REMOTE SUBNET   14 devices missing
OTHER IT APPS   Normal
ROUTER CHANGE   Completed 35 min ago
CONTROLLERS     Reported powered
LOCAL POINTS    Updating

Build the investigation on paper: identify the common boundary, the networking tests, and where BACnet broadcast management enters. Do not assume 14 simultaneous controller failures.

04 / INCIDENT OPS-103

Cooling alarm with conflicting evidence

AHU-07 SAT      78.9°F
SETPOINT        55.0°F
FAN             ON
VALVE CMD       100%
VALVE FEEDBACK  12%
TREND           SAT rising for 18 min
OTHER AHUs      Normal
NETWORK         No communication alarms

Separate command from feedback. Decide what the BMS evidence supports, what it does not prove, and what physical verification should happen next under site procedures.

05 / FINAL CHALLENGE

Build your incident dossier

V1 EVIDENCE RULE

Your saved capstone response is OPS-101 above. Complete that written response as the required V1 dossier. OPS-102 and OPS-103 are additional integration drills.

  1. Use OPS-101 as the required written dossier for V1.
  2. Write a one-sentence problem statement without naming an unproven cause.
  3. Define scope and blast radius.
  4. Create at least three ranked hypotheses based on evidence.
  5. For each hypothesis, define a discriminating test and expected result.
  6. Identify the safest next operational action.
  7. Write a concise escalation handoff with evidence, timestamps and unresolved questions.
  8. Explain the incident verbally as if answering a technical interview question.

06 / READINESS CHECK

Integration, not memorization

1. DNS, ping and TCP 443 succeed, but the application returns HTTP 500. Where should investigation increasingly focus?
2. Fourteen remote BACnet devices disappear together after a router change while local devices remain normal. What is the strongest clue?
3. Valve command is 100% but feedback is 12% while temperature rises. What is the correct interpretation?
