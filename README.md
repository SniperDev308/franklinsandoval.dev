# franklinsandoval.dev — Showroom v1

Static deployment package for Cloudflare Pages or any static host.

## Files
- `index.html` — main showroom
- `styles.css` — responsive visual system
- `script.js` — navigation interactions
- `dc-simulator.html` — placeholder route for the future simulator
- `assets/reference-mockup.png` — current visual reference used in the hero

## Deploy
Upload the full contents of this folder to the root of a static hosting project.
No build command is required.
